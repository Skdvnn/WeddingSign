Printing them

These are paper, not paint — the welcome-sign constraints don’t apply. The constraint is matching the stationery that’s already in people’s houses.

Stock

  • Bone / cream cardstock is the honest match to the invite. If you can get close to #E7E3DA, use it. White will look like a different suite sitting on the table.
  • 5 × 7 in, portrait. Each card’s Print 5×7 button sends one layout to the printer at actual size. In the print dialog: paper size 5×7 (or A5 cropped), no margins, scale 100%.
  • Print a single test on the real stock before the set. Photos shift warmer on cream; black type does not.

Photos

  • Upload a pair per age. The sample pictures are from the sketches so you can judge layout — replace them before you print.
  • Crop generously. Every layout uses cover, so faces near the edge will get clipped. Give the eyes some air.
  • Scan at 300 dpi or better. A 5×7 photo slot is roughly 2.2 × 3.2 in; that’s only ~660 × 960 px at print, but start from the full scan.

What ties this to the rest of the wedding

  • The number sits on the stock, never on a photograph. Guests find the table from the numeral. They look at the pictures second.
  • Faces stay in the clear. Crops are pulled toward the upper third of each scan. If a face is getting clipped, swap the photo — don’t put type on it to “fix” it.
  • A1 and A2 are the ones you already liked. Everything else is a quieter or louder version of those two.

Fonts (same suite as the welcome sign)

  • Instrument Serif for the display lines — “When we were,” the age numeral, guest names if you add place cards. It’s the invite face; don’t swap to Bodoni / Didot just because the screen looks fancy — those hairlines fall apart at print size the same way they would on the mustard board.
  • Roboto Mono for the small caps / pair line (ALLISON + SKYLAR), tracked wide (~0.12–0.2em). That wide mono is half of why the suite feels intentional.
  • If you lock the welcome to S2 · Display Stack (mustard + Instrument stack + italic &), keep the cards on bone stock, not mustard — the painted A-frame can shout colour; the table cards should whisper the same type on paper.
  • Escape hatch if Instrument’s hairlines look thin on a test print: DM Serif Display (same silhouette, thicker strokes). Keep Roboto Mono for details either way.
