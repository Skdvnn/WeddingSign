Printing it

Paper, like the table cards — not paint. The constraint is matching the stationery that’s already in people’s hands.

Stock

  • Bone cardstock is the honest match to the invite and the 5×7s. If you can get close to #E7E3DA, use it.
  • Mustard board is a labeled option in Type tools — only if this sign stands next to the painted welcome A-frame and you want them to read as a pair. Default is bone.
  • Export PDF is the bartender file: allison-skylar-bar-menu.pdf, one page at the card’s 1545 × 2000 portrait — no nav, no tools, no browser chrome. Not stretched to a different paper.
  • 1545 × 2000, portrait — the mock’s 3:4. Print this layout uses the same aspect.

What ties this to the rest of the wedding

  • Instrument Serif for drink names — the invite face, same as Allison / Skylar and “When we were.” Italic the ampersands.
  • Roboto Mono for the header, tags, and ingredients, tracked wide (~0.13–0.2em), all-caps like the rest of the suite.
  • Lettering is black #1E1D1A. Mustard is used once: a rule (two-column), a tag (tag column), or a block (ledger header) — never sprinkled, never a third loud colour, and never the cream-with-purple-green of the rejected mock.
  • Solid ink only. No opacity, no leaf frames, no stacked brown “BAR MENU.”
