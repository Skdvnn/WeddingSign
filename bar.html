Lockup

Printing it

Paper, like the table cards — not paint. The constraint is matching the stationery that’s already in people’s hands.

Stock

  • Bone cardstock is the honest match to the invite and the 5×7s. If you can get close to #E7E3DA, use it.
  • Mustard board is a labeled option in Type tools — only if this sign stands next to the painted welcome A-frame and you want them to read as a pair. Default is bone.
  • Mustard mix in Type tools: #BFA52B is the napkin / painted board and prints lemon on paper. Use Print (#C5BA2D) for the next bar print — the mustard-board fill from the preferred PDF. Curry (#9A9322) stays as a compare chip. If Print is still school-bus, nudge Hue toward olive or try Dijon. Table cards should stay on bone; if a 5×7 is mustard, use the same Print mix — don’t reprint Screen.
  • Export PDF is the bartender file: allison-skylar-bar-menu.pdf, one page at the card’s 1545 × 2000 portrait — no nav, no tools, no browser chrome. Not stretched to a different paper.
  • 1545 × 2000, portrait — the mock’s 3:4. Print this layout uses the same aspect.

What ties this to the rest of the wedding

  • Instrument Serif is the default drink-name face — the invite face, same as Allison / Skylar and “When we were.” Italic the ampersands. Type tools → Drink names → Roboto switches the four names to the suite Roboto (not Mono).
  • Roboto Mono is the default for the header, tags, and ingredients, tracked wide (~0.13–0.2em), all-caps like the rest of the suite. Type tools → Bar header → Roboto sets BAR MENU to the same Roboto as the names.
  • Lettering is black #1E1D1A. Mustard is used once: a rule (two-column), a tag (tag column), or a block (ledger header) — never sprinkled, never a third loud colour, and never the cream-with-purple-green of the rejected mock.
  • Solid ink only. No opacity, no leaf frames, no stacked brown “BAR MENU.”
  • Also pouring is a sticky toggle — on by default, saved in this browser. Beer and wine stay a secondary chapter, never a fifth cocktail card. B9 and B30 are the DNA: hairline, then Beer | Wine. B38–B45 are cousins of that (centered / verse / ledger / loose type, double plate, cap rules, cocktail-only plate, split plates). B34–B37 keep the earlier rail / pane experiments. Heroes scale back a hair when the band is on. PDF / PNG / SVG / print include the band when the toggle is on.
